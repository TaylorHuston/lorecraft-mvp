# ADRs

Architecture Decision Records explain durable technical or product-architecture choices for Lorecraft.

Epics and Stories remain the source of truth for implemented behavior. ADRs explain why a significant decision was made, what alternatives were considered, and when to revisit it.

## When To Add One

Add an ADR when a change introduces or revises a durable decision about Game Master authority, persistent-world state, provider/model strategy, extraction boundaries, deployment, security/privacy posture, generated artifacts, or other tradeoffs that future maintainers are likely to question.

Use the shared template at `../../../../shared/templates/docs/adrs/adr.md-template.md`.
